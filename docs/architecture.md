# Архитектура

Целевая платформа: Windows 7 SP1 x64, .NET Framework 3.5, Windows Forms. Пользователь запускает один `VPN.exe`; интерфейс не требует выбора движка.

| Файл | Назначение |
|---|---|
| `App.cs` | Запуск, управление подключением, сохранение данных, восстановление прокси и надзор за процессом |
| `SimpleUI.cs` | Главное окно, настройки, значок и окно трея, выгрузка журнала |
| `Core.cs` | Разбор профилей и ссылок, создание конфигураций движков |
| `Subscription.cs` | HTTPS-загрузка, выбор формата, идентификация сервера и структура сохранённой подписки |
| `Telemetry.cs` | Реальные счётчики трафика и проверка HTTPS через локальный прокси |
| `Diagnostics.cs` | Журнал, ротация и запись разрешённых диагностических полей |
| `Assets.cs` | Загрузка встроенной библиотеки и извлечение проверенных компонентов |
| `SelfTest.cs` | Проверка автономной упаковки и отрисовки окон на Windows |

## Подключение

1. Ссылка подписки проверяется и нормализуется; метка после `#` не отправляется серверу.
2. Ответ преобразуется в локальный список серверов. Поддерживаемые варианты заглушек удаляются.
3. Стандартный VLESS/TCP/REALITY выбирает Xray; остальные поддерживаемые профили — Mihomo. Это фиксированные правила, а не перебор движков при сетевой ошибке.
4. Конфигурация проверяется отдельным запуском движка до изменения системного прокси.
5. После готовности локального слушателя сохраняется снимок прежних настроек и включается системный прокси текущего пользователя.
6. Отдельный надзорный процесс восстанавливает настройки после завершения основного процесса. После отключения питания восстановление выполняется при следующем запуске.

## Статистика и состояние

Для Xray включается локальный `StatsService`, для Mihomo — контроллер на loopback с одноразовым токеном. Счётчики относятся к текущему движку, а не к сетевому адаптеру Windows. Доступность проверяется HTTPS HEAD-запросом к `example.com` через локальный прокси. Программа не обещает полный перехват трафика всех приложений.

## Упаковка

Скрипт сборки встраивает сжатые движки, YamlDotNet и лицензии как ресурсы. YamlDotNet загружается из памяти; движки извлекаются в личный каталог пользователя и проверяются по SHA-256. `Assets.cs` содержит ожидаемые хеши: изменение версий зависимостей требует осознанного обновления этих значений и повторных проверок.

Имя внутреннего пространства `MihomoDesk` и каталог данных сохранены для совместимости с уже установленной версией. В пользовательском интерфейсе приложение называется VPN.
