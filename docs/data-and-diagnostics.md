# Данные и диагностика

Данные хранятся в `%LOCALAPPDATA%\MihomoDesk` отдельно для каждой учётной записи Windows. Код не содержит рабочих подписок или серверных ключей.

| Файл / каталог | Содержимое |
|---|---|
| `subscription.dat` | URL подписки, серверы, выбор и дата обновления; защита Windows DPAPI |
| `profiles.dat` | Прежний формат локальных профилей; сохранён для совместимости |
| `recovery.dat` | Защищённый DPAPI снимок настроек прокси и идентификаторы процессов |
| `runtime.json` | Рабочая конфигурация с реквизитами в открытом виде на время подключения |
| `device-id.txt` | Случайный ID установки, постоянный между обновлениями; это не ключ подписки и не отпечаток оборудования |
| `bin-0.7/` | Извлечённые компоненты |
| `diagnostics.log`, `.1`, `.2` | Текущий и два архивных журнала, примерно до 1 МБ каждый |

DPAPI защищает сохранённые данные в контексте текущего пользователя Windows. Это не защита от вредоносной программы, уже работающей с его правами. Рабочая конфигурация нужна движку и удаляется при отключении или восстановлении.

В журнал попадают только предусмотренные структурные поля: этап, число серверов, HTTP-статус, тип исключения, категория ошибки, состояние процесса. Сырые ответы подписки, URL, пароли, UUID и ключи не записываются. Время событий — UTC.

Пользователь передаёт файл через **«Сохранить журнал»**. Нельзя просить его отправить всю папку данных или `runtime.json`.

Перед коммитом:

```bash
python3 scripts/check-secrets.py
git status --short
```

Эта проверка ищет распространённые признаки секретов и не заменяет просмотр diff. Не добавляйте личные конфигурации, ключи SSH, `.env`, логи или готовые бинарники. Для тестов используются только синтетические значения.

Некоторые провайдеры учитывают устройства по HWID. Приложение отправляет свой случайный ID только после явного ответа сервиса `X-Hwid-Active` + `X-Hwid-Not-Supported`. Регистрация может занимать один слот подписки. Чужие идентификаторы не копируются, аппаратные идентификаторы не считываются, при повреждении файла новый ID автоматически не создаётся. Значение не включается в журнал.
