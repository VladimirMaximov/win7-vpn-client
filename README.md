# win7-vpn-client

[**Скачать VPN.exe**](https://github.com/VladimirMaximov/win7-vpn-client/releases/latest/download/VPN.exe) · [Все релизы](https://github.com/VladimirMaximov/win7-vpn-client/releases)

Простой клиент для **Windows 7 SP1 x64**: одна кнопка подключения, подписки и прямые ссылки серверов, статус и скорость трафика в трее, журнал для помощи с настройкой.

Для запуска нужен один файл `VPN.exe`. Приложение само выбирает сетевой движок; пользователю не нужно настраивать протоколы вручную.

> Приложение работает через системный HTTP-прокси: его используют браузеры и совместимые приложения. Полного перехвата трафика всех программ — режима TUN — сейчас нет.

## Требования

- Windows 7 SP1, **64 бита**. Сборки для 32-битной Windows пока нет.
- Включённый **.NET Framework 3.5.1**, входящий в Windows 7.
- Интернет и действующая подписка с поддерживаемой конфигурацией.
- Для HTTPS-загрузки подписок нужны рабочие TLS 1.2, корневые сертификаты и правильные дата и время Windows.

На Windows 7 x64 приложение и оба движка проверялись. Другие версии Windows и все редакции/сборки Windows 7 отдельно не сертифицировались.

## Установка и первый запуск

Инсталлятора нет:

1. Возьмите `VPN.exe` из готовой сборки и сохраните, например, на рабочем столе. Если у вас только исходники, сначала выполните [сборку](#сборка-из-исходников): результат появится в `dist/VPN.exe`.
2. Запустите `VPN.exe` обычным двойным щелчком. Права администратора для штатной работы не нужны.
3. Нажмите **«Добавить подписку»**, вставьте HTTPS-/HTTP-ссылку своего VPN-сервиса или прямую ссылку сервера и нажмите **«Сохранить»**. Ссылку можно вставлять целиком, включая метку вроде `#PaperVPN`.
4. Выберите сервер и нажмите **«Подключить»**.
5. Дождитесь статуса **«Подключено»** и проверьте нужный сайт в браузере. Браузер должен использовать системные настройки прокси.

При первом запуске программа извлечёт встроенные компоненты в личную папку Windows. Другие EXE и DLL рядом с `VPN.exe` не нужны. На пользовательском компьютере не нужны Python, Git или современный .NET SDK.

Если Windows сообщает об отсутствии .NET, откройте **Панель управления → Программы → Включение или отключение компонентов Windows** и проверьте компонент **Microsoft .NET Framework 3.5.1**.

## Ежедневное использование

- Подписка, список серверов и выбранный сервер сохраняются. При следующем запуске достаточно нажать **«Подключить»**.
- Для выбора другого сервера сначала отключите соединение.
- Закрытие главного окна **сворачивает приложение к часам**, а не завершает подключение.
- Нажатие на значок возле часов открывает небольшое окно со статусом и скоростями; двойное нажатие открывает главное окно. Значок может находиться под стрелкой скрытых значков Windows.
- Правое нажатие на значок открывает меню, в том числе **«Отключить»** и **«Выход»**.
- При отключении или выходе программа восстанавливает прежние настройки системного прокси, если их не изменила другая программа.

**Входящий/исходящий трафик** — счётчики текущего подключения, а не всего компьютера. Для проверки доступности через VPN выполняется HTTPS HEAD-запрос к `example.com` примерно раз в 30 секунд. Статус **«Проверка не прошла»** означает, что проверочный сайт не ответил: это не всегда означает недоступность остальных сайтов.

## Подписки и обновления

В **«Настройки»** доступны добавление/замена подписки, обновление серверов, импорт файла, удаление подписки и журнал.

Перед подключением приложение обновляет подписку, если её сохранённые данные старше шести часов. Это проверка **при подключении**, а не фоновое расписание. Можно обновить серверы вручную. Если загрузка или сохранение новой подписки не удались, прежние рабочие данные сохраняются.

В окно добавления можно вставить одну ссылку или список ссылок серверов, по одной на строку. Подписки по HTTP требуют подтверждения: они передают ссылку и настройки без шифрования. HTTPS-перенаправления на HTTP запрещены. Прямые ссылки сохраняются локально без автоматического обновления.

Поддерживаются:

- списки ссылок VLESS, VMess, Trojan, Shadowsocks, Hysteria 2;
- base64-подписки с такими ссылками;
- совместимые YAML/JSON-профили Mihomo с массивом `proxies`.

Для ONET реализовано согласование идентификатора устройства: если сервис явно требует его, приложение повторяет запрос с постоянным случайным ID своей установки. Серийные номера, MAC-адрес и имя пользователя не отправляются. Лимиты устройств сервиса не обходятся.

Поддержаны также VLESS XHTTP, дополнительные параметры gRPC/TLS и параметр `fm` для Hysteria 2 с передачей в Xray. Проверка конфигурации не означает проверку доступности каждого сервера.

Конкретные транспорты и расширения имеют ограничения. Внешние `proxy-providers`, YAML-якоря/теги и прямой импорт JSON Xray/sing-box не поддерживаются. Из файла импортируются серверы, а не его DNS, правила маршрутизации или группы. Неизвестные параметры не должны молча заменяться другими.

Некоторые сервисы ограничивают сторонние приложения и вместо серверов выдают `app not supported`. Такая заглушка отклоняется. Наличие формата подписки в списке не гарантирует совместимость с любым провайдером.

## Если возникла проблема

1. Нажмите **«Сохранить журнал»** в главном окне или меню значка.
2. Выберите место для файла `VPN-diagnostics.log`.
3. Отправьте **этот файл** человеку, который помогает с настройкой. Полезно указать, какое действие не получилось.

Приложение не записывает в журнал URL подписки, пароли, UUID и ключи. Вместо сырых ответов сервера и строк движка сохраняются этапы работы, HTTP-статусы и категории ошибок.

**Не отправляйте всю папку данных приложения.** Во время подключения там есть временная конфигурация с реквизитами доступа. Подробнее: [данные и диагностика](docs/data-and-diagnostics.md).

## Сборка из исходников

Готовые EXE, загруженные зависимости и личные настройки в Git не хранятся.

Для разработчика нужны **Python 3.10+** и один из вариантов:

- на Windows — компилятор установленного .NET Framework 3.5;
- для кросс-сборки на macOS/Linux/Windows — **.NET SDK 8**. Скрипт использует reference assemblies .NET Framework 3.5; приложение не переводится на .NET 8.

Из корня репозитория:

```bash
python3 scripts/prepare-deps.py
python3 scripts/build.py
```

В Windows команда обычно называется `python`:

```powershell
python scripts\prepare-deps.py
python scripts\build.py
```

Также можно запустить `scripts\build.cmd`. Если нужно явно указать .NET SDK для кросс-сборки:

```bash
python3 scripts/build.py --dotnet /path/to/dotnet
```

Результат:

```text
dist/
├── VPN.exe
└── VPN.sha256
```

Скрипты скачивают фиксированные версии с официальных GitHub/NuGet-адресов и сверяют SHA-256 архивов и извлечённых файлов. Зависимости сохраняются в игнорируемой папке `.deps/`, промежуточные ресурсы — в `artifacts/`.

Рядом есть `win7-vpn-client.sln` и проект для навигации в Visual Studio. Встроенные ресурсы для него сначала формируются основным скриптом сборки.

## Тесты

Для переносимых тестов нужен **.NET SDK 8**:

```bash
python3 scripts/test.py
python3 scripts/check-secrets.py
```

Если `dotnet` не находится в `PATH`:

```bash
python3 scripts/test.py --dotnet /path/to/dotnet
```

Тесты используют искусственные реквизиты и ответы подписок. Они проверяют импорт, сохранение данных, выбор сервера, обработку заглушек, приватность и ротацию журнала. Они не подключаются к личным VPN-серверам. При подготовке зависимостей может понадобиться Интернет.

Отдельный интеграционный тест работает только через loopback и требует Mihomo **для той ОС, на которой запускается тест**:

```bash
python3 tests/integration/local_vless.py --engine /path/to/mihomo
```

В Windows можно указать `.deps/mihomo.exe`. Windows-бинарник из `.deps` не запускается нативно на Mac. Локальный тест не проверяет REALITY или доступность внешнего VPN-сервера.

## Структура репозитория

```text
src/VpnClient/            C#-код приложения
resources/               Значок приложения
scripts/                 Подготовка зависимостей, сборка, тесты, проверка секретов
tests/                   Переносимые тесты и локальный интеграционный тест
docs/                    Архитектура, данные и диагностика
third_party/             Фиксированные версии, контрольные суммы и лицензии
.deps/                   Загружаемые зависимости — не в Git
artifacts/               Промежуточные файлы и результаты тестов — не в Git
dist/                    Готовая сборка — не в Git
```
